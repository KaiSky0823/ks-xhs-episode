# 06 · 实战复盘：常见返工坑

这份清单用于每集复盘，记录可复用的失误模式和防线；不依赖某一账号的私人对话或个人经历。出现新问题时，补「可复现条件、根因证据、回归测试」，不要只写结论。

## 1. 主线错了，出图后才发现

**常见表现**：选题看起来很有趣，但核心结论只来自二手摘要；或者核查以后证据比流行说法弱很多，原来准备的反转讲不成立。

**防线**：先核查，再定四张结构；证据等级不足时先改题 / 改表述，不先画再找依据。

## 2. 摘要层错误传进画面

摘要、新闻稿和二手转述可能把数字、实验对象、限制条件说错。精确数字、物种特征、时间、方向、对照条件都回原始研究核对；找不到原文就降低表述强度或停下。

**防线**：核查结论表记录来源、实际读到的层级、可用表述和不能推出的结论；不能把搜索摘要写成「原文确认」。

## 3. 否定断言比肯定断言更容易越界

「没人测过」「没有证据」「查无出处」需要更高证据门槛；搜不到只能说明当前检索没找到，不等于不存在。

**防线**：记录检索范围和可访问的一手资料；没有全文证据时改成「本次查到的来源中未找到」。

## 4. 门禁也会误报 / 漏报

门禁的 regex、几何阈值和资源检测都可能被模板结构或特殊排版绕开，也可能拦到正常的功能符号。

**防线**：每个规则配正例、反例、绕过例；升级门禁时对已发布卡回归，分别统计新增 FAIL / WARN，不把「脚本通过」当成人眼验收。

## 5. 图像文件的扩展名不代表文件格式

生图 API、代理脚本、下载或保存失败都可能让 `.png` 后缀对应 JPEG 或截断图；裁切、拉伸也会改变高频纹理与构图位置。

**防线**：检查魔数、完整解码、尺寸和比例；对付费 API 的重试留痕，提示重复请求可能重复计费。

## 6. 视觉构图与事实断言分开审

门禁可以查溢出、字号、颜色和部分资源状态，查不了箭头是否指对、主体朝向、数量、尺度、读者会把某个道具理解成什么。

**防线**：把每个可被误读的形状、道具和相对位置都当作断言；至少做一次整图人眼复核和冷读。

## 7. 复盘记录格式

| 字段 | 记录内容 |
|---|---|
| 现象 | 什么输入 / 操作后出现了什么 |
| 根因证据 | 文件、原始数据、可复现步骤；把推断单独标出来 |
| 修复 | 改了什么，以及影响范围 |
| 回归 | 同类正确样本放行、缺陷样本拦截；记录退出码和数量 |
| 未决 | 需要内容负责人或读者裁定的视觉 / 语气取舍 |
