# 02 · 核查协议 ★本 skill 的核心★

一集的成败在这一步。九集的经验：**核查做透，出图和文案都很顺；核查偷懒，出图后返工。**

## 派谁去查

按选题复杂度派 **2-4 路 Sonnet agent 并行**，分工不重叠：

| 路 | 任务 | 必须要求 |
|---|---|---|
| A | **原始文献与机制** | 找到奠基论文的作者/年份/期刊/卷页；要原句；要 N 和效应量 |
| B | **重复实验与争议** | 有没有人没重复出来？有没有后续推翻？最新几年有没有反转 |
| C | **中文互联网流传版本** | 大家怎么讲的、哪里讲错了、有没有编造的数字 ← 辟谣素材都在这 |
| D | **彩蛋与延伸** | 相关的怪事、临床应用、历史八卦、同类现象 |

简单选题合并成 2 路（A+B、C+D）。

### 派单模板（照抄改）

```
任务：为小红书科普「<现象>」做发布级事实核查。只用 WebSearch/WebFetch，
上限 <20-25> 次调用，<10-12> 分钟内返回。
每条给：结论 / 原句或数字 / URL / 强度（一手全文 / 一手摘要 / 二手 / 未证实）。
优先开放全文（PMC、作者主页、J-Stage 旧刊、大学仓储）。

要核的：
1. <具体到论文题名/作者/年份>
2. ...

最后给：「可以印在图上的 3～5 条硬事实」「绝对不能写的过强说法」。
```

**每条都要显式写 `model: "sonnet"`**（非 Claude 主循环下省略会 403，见全局纪律）。

## 强度分级

| 档 | 定义 | 能不能上图 |
|---|---|---|
| **一手全文** | 我本人或 agent 读到了论文全文里的那句话/那个表格 | ✅ 可以，数字可精确 |
| **一手摘要** | 读到了官方摘要页的原句 | ✅ 可以，但别超出摘要说的范围 |
| **二手** | 百科、权威科普站（AAO、疾控）、综述转述 | ⚠️ 可以，但要标来源性质；别说「研究发现」 |
| **未证实** | 只在自媒体/网页搜索摘要里见过 | ❌ 不上图 |

## 我自己必须做的三件事

agent 是线索提供者，不是结论提供者。**这三件事不能外包**：

### 1. 载重结论亲自读原文

图上最核心的那几个数字，我自己抓 PDF、`pdftotext` 直读。
开放全文常见渠道：J-Stage 旧刊、大学机构仓储（era.ed.ac.uk 之类）、PMC、作者实验室主页、Europe PMC 的 `fullTextXML`。

```bash
pdftotext -layout 论文.pdf 论文.txt      # 日文/中文 PDF 也能抽
python3 -c "import re;t=re.sub(r'\s+',' ',open('论文.txt').read());print(t[t.find('Results'):][:2000])"
```

### 2. agent 冲突时我裁定

两路说法不一致 → **以我读到的原文为准**，并把裁定过程写进核查结论。
实战案例见 `06-九集复盘.md` §2。

### 3. 否定断言必须全文层证据

「没人测过」「查无出处」「没有研究」——agent 搜不到只能证明「摘要层没有」。
**精确到小数点的网传数字，先假设它有源头**，去找它；找不到才写「未能追到出处」，而不是「查无出处」。

## 核查结论怎么写

落盘到 `第N集-XX/报告/核查结论.md`，模板见 `../templates/核查结论.md`。必须有三节：

1. **可以印在图上** —— 表格：表述 / 依据（含原句）/ 强度
2. **绝对不能写** —— 逐条，每条说明为什么
3. **来源** —— 可点击的 URL 列表

另外记两样：
- agent 和我打架的地方，以及我按什么裁的
- 这轮**没做到**的（付费墙、渠道挂了、时间不够），诚实写出来

## 安全与健康题材的额外一条

涉及身体、疾病、食品安全时，**必须给出边界提醒**，而且不能只说「没事」。
第 9 集的例子：蓝视野现象本身良性，但**突然新增**的飞蚊/闪光是视网膜脱离预警，必须就医——这条不能省。
