# 03 · 四张图的内容职责

⚠️ 这里只讲**每张图要承担什么内容**。字号、色板、角度、几何约束、门禁全在 `08-视觉规范.md`。

## 标准是四张

钩子 / 答案 / 机制图示 / 彩蛋。

**第 3 集破过一次例（五张）**：因为要让读者先被骗一次再解释，把机制拆成「出题 / 揭晓」两张。
这是**内容需要时的例外**，不是新标准。第 4 集起回到四张。

---

## ① 钩子

**职责：让读者认领这件事。**

- 直说现象，别绕。第 3 集初稿写「那个『啊』」被 Kai 打回，因为太隐晦。
- 主题必须在首图出现。标题党可以，谜语人不行。
- 结论可以先给一半（「它没在点头」「真的有，但没传说的那么邪乎」），制造往下看的理由。
- **能当场验的选题，首图就给操作说明**（盯 26 秒、看蓝天怎么看）。这是参与感的来源。
- 角色（?怪 / !怪）要在「做事」，不是站着当贴纸。

## ② 答案

**职责：一句话把机制说清，再给一个反常识的钉子。**

- 结论先行，第一屏就给答案。
- 答案要有一个**可视化的比喻**：脑子按房间建档、头当眼珠用、白细胞是透光的缺口。
- 底部留一个数据块或一条反转（「走回去也没用」「不是为了平衡」）。
- 标题 ≤ 8 字（DNA 的硬约束，门禁拦不住）。

## ③ 机制图示

**职责：把因果画出来，不是把结论列出来。**

这是最容易做砸的一张。第 3 集初稿就是栽在这里——画的是「两个啊一样强」（统计结果），
不是「骗局怎么运作」（机制）。

判断标准：**把文字全删掉，图还能讲明白吗？**

有效的形态：
- 分帧定格（鸽子四帧，头始终在一条线上）
- 左右对照（站着 vs 躺着的叮咬热区）
- 排除法（三个猜想逐条打叉，剩下一个）
- 剖面放大（毛细血管里的红细胞 / 白细胞 / 暗尾）
- 路径图（硬顶死路 vs 暂时退出换条路）

## ④ 彩蛋

**职责：给一个能单独转述的新东西，不是复述主结论。**

已验证有效的彩蛋类型：
- 出处打假（72% 是卖花洒的做的）
- 名不副实（论文叫《The Shower Effect》，实验里没人洗澡）
- 实验事故（跑步机没关严，鸽子脖子越伸越长，栽了）
- 认错冒牌货（钉螺 ≠ 螺蛳，福寿螺 ≠ 螺蛳）
- 反差年代（1924 年命名，比 OCT 早 67 年）
- 翻两面（想象走门也会忘 / 但 2021 年大部分条件没复现）

**最后一句要能被截图转发**。写法：短、具体、有画面。
> 卡住先离题，不必先脱衣服。
> 躺下，你的脸就是脚踝。
> 门不是橡皮擦，是你脑子太忙时多出来的一道岔口。
> 最便宜的一台显微镜，一直装在你脸上。

## 出图后人眼必看

门禁（`social-card-qa.mjs`）测不到的，九集踩出来的清单：

1. **绝对定位块之间叠压** —— 门禁测的是文字行，两个 `position:absolute` 的块压在一起它不报（第 9 集彩蛋踩过）
2. 文字压在右上网点上
3. SVG 主体被画布裁掉（脖子伸太长、身体超出 viewBox）
4. 标注指错了位置（咬痕没落在脚踝上、「蓝光进来」标在右边但光从左进）
5. 同色剪影糊成一坨
6. 图示语义撒谎（刻度不等分、位置暗示了错误因果）
7. 中间大片空白（覆盖率 WARN 只是提示，得自己看）

看完再给 Kai。给的是 `_全四张.png` 拼版，不是单张。
