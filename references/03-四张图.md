# 03 · 四张图的内容职责

⚠️ 这里只讲**每张图要承担什么内容**。字号、色板、角度、几何约束、门禁全在 `08-视觉规范.md`。

## 标准是四张

钩子 / 答案 / 机制图示 / 彩蛋。

**当前工具链固定支持四张**：钩子 / 答案 / 机制图示 / 彩蛋。若内容确实需要五张，先扩展模板、文件命名和 `shot.js` 去 AI 味闸并跑回归；未扩展前不得把第五张当定稿交付或绕过门禁。

---

## ① 钩子

**职责：让读者认领这件事。**

- 直说现象，别绕；标题和画面让读者先认出主题，再看解释。
- 主题必须在首图出现。标题党可以，谜语人不行。
- **封面不用比喻**（试稿复盘）：用「人人经历过的瞬间 + 话题词放大字 + 一句人话」。比喻放后面的卡里当辅助，不能让它扛第一屏的信息。话题词（读者搜的那个词）必须在大字里，不在最小的一行。
- 封面图里的主体要 3 秒认得出：图标至少 80 像素，别画成胶囊 / 香肠让读者猜是不是手臂，认不出就在旁边写一句字。
- 结论可以先给一半（「它没在点头」「真的有，但没传说的那么邪乎」），制造往下看的理由。
- **能当场验的选题，首图就给操作说明**（盯 26 秒、看蓝天怎么看）。这是参与感的来源。
- 角色（?怪 / !怪）要在「做事」，不是站着当贴纸。画法：生物、表情、姿态承担内容的走生图（吉祥物要嘴、要亲、要和别的生物互动才用参考图，代码眼型够用就代码，见 12），图示、数据、剖面、物件、场景、微生物走代码（12 第一节的三个例外）。非人物题里吉祥物选一种职责（读者替身 / 抬头看或指向 / 吃亏的人 / 动手做实验），见 12 第二节。
- **先定情绪目标**（2026-10-22 流程更新）：写结构时先用一句话写「读者看完封面 3 秒该感到什么」（搞笑 / 浪漫 / 恶心 / 惊讶 …）和「画面能不能承担」。接吻、拥抱、哭、害怕这类要靠人脸和身体接触才成立的情绪，**代码画的** ?怪 / !怪 演不出来；可以走生图：吉祥物加参考图能亲吻、长嘴、做表情，但示例 探索性冷读读出的是「滑稽」不是浪漫（1 份冷读，用的是造型漂移的那张，未定论，见 12 第三节）；目标是浪漫、温暖就用生图人物。恶心、害怕是有上限的情绪：要的是「轻一点」，写实度越高越容易越线，往代码、低写实度走（11 第七节、12 第一节例外 3）。「被打脸」靠传言和真相的对照，代码就能承担（见下文「辟谣题的画面」）。画法要在定结构时选好，别画完才发现。冷读时用 `11-通俗度与冷读测试.md` 第七节的三问去测。情绪目标写在 `方案_v1.md`（模板 `templates/方案.md`）。

## ② 答案

**职责：一句话把机制说清，再给一个反常识的钉子。** 画法：故事里的人物 / 生物走生图，场景背景（夜空、泳池、厕所）走代码画在框底，答案里的箭头、数字、标注走代码。

- 结论先行，第一屏就给答案。
- 答案要有一个**可视化的比喻**：脑子按房间建档、头当眼珠用、白细胞是透光的缺口。**比喻只是辅助**：结论必须先用人话写在导语两行里；比喻不能再叠术语和研究局限（曾有答案卡把比喻、术语和研究局限叠在一张图上，理解成本过高）。
- 底部留一个数据块或一条反转（「走回去也没用」「不是为了平衡」）。
- 标题 ≤ 8 字（DNA 的硬约束，门禁拦不住）。

## ③ 机制图示

**职责：把因果画出来，不是把结论列出来。**

机制图容易把统计结果画出来，却没有呈现因果过程；先确认图要解释的关系，再决定画法。

判断标准：**把文字全删掉，图还能讲明白吗？**

有效的形态：
- 分帧定格（鸽子四帧，头始终在一条线上）
- 左右对照（站着 vs 躺着的叮咬热区）
- 排除法（三个猜想逐条打叉，剩下一个）
- 剖面放大（毛细血管里的红细胞 / 白细胞 / 暗尾）
- 路径图（硬顶死路 vs 暂时退出换条路）

## ④ 彩蛋

**职责：给一个能单独转述的新东西，不是复述主结论。**

已验证有效的彩蛋类型：
- 出处打假（72% 是卖花洒的做的）
- 名不副实（论文叫《The Shower Effect》，实验里没人洗澡）
- 实验事故（跑步机没关严，鸽子脖子越伸越长，栽了）
- 认错冒牌货（钉螺 ≠ 螺蛳，福寿螺 ≠ 螺蛳）
- 反差年代（1924 年命名，比 OCT 早 67 年）
- 翻两面（想象走门也会忘 / 但 2021 年大部分条件没复现）

**彩蛋要能单独转述的是那个新东西，不是最后一句金句。** 收尾句按下一节的规则写。

## 辟谣题的画面

辟谣题（「手机比马桶脏 10 倍」「五秒定律」「敲罐防喷」）最大的坑是**封面替传言作证**：大字写传言、画面画出传言，读者只看封面就把错的带走了。

1. 封面可以出现传言原句，但传言里的数字必须带问号或「传言」戳（代码画），不许单独成为大字。
2. 画面不能替传言作证：不画「爬满细菌的手机」「喷出水柱的马桶」这类把传言画成事实的图。
3. 线索链 / 出处图里，每一节的线型跟核查强度走：一手 = 实线，二手 = 虚线，未证实 = 灰色问号；不能为了干净全画实线。
4. 「查不到」只能写成「没找到对比数据」；「假的」「查无出处」要有全文层证据（SKILL 第四条底线）。
5. 两边对照的物件同大、同样干净（本文末节「两边的视觉重量要对等」）。

`templates/方案.md` 里「传言原句 / 源头 / 核查强度」辟谣题必填；核查结论和流行说法相反时，先向内容负责人确认是否接受「半辟谣」走向（SKILL「什么时候停下来问本人」）。

## 每张卡底部那一句（收尾句规则，2026-10-17 起）

旧规矩写的是「最后一句要能被截图转发：短、具体、有画面」，还配了一串例句。照着写出来的全是金句：
对仗两半、「不是 X，是 Y」、「A 等于 B」。历史卡片回归中，脚本发现收尾句常出现对仗和格言式表达。旧规矩作废，例句一并删除。

`.final` / `.foot` 那一句只能是下面三种之一：

| 类型 | 例 | 要求 |
|---|---|---|
| **一个具体事实** | 他戴着浴帽、抱着橡皮鸭去领奖。<br>两千年前就有人问，现在还没有定论。 | 核查结论里有出处；平铺直叙，不加评价 |
| **一个具体邀请** | 冷水热水各试一次 看帘子往哪边飘 | 只写一个能做的动作，**不求评论**（不写「评论区说一声 / 告诉我 / 聊聊」，脚本 H11 硬拦）；动作真能做到、安全的才写；健康类先看 04 的安全条款 |
| **不写** | 整块删掉，让上面最后一块内容当结尾 | **默认选项，拿不准就不写** |

不许：对仗的两半、格言（「X，等于 Y」「X 才是 Y」）、比喻收尾、「所以说…」、拔高到「科学 / 人生 / 世界」。
写出自己觉得漂亮的那一句，**先怀疑它**——那是在表演，不是在说话。
唯一的口子：**内容负责人明确批准的一句，每集最多 1 句**（做法见 `10-去AI味规则集.md` §一）。未获批准就改掉。

## 每张卡的文字块（已验证规格）

复盘中反复发现：限定框重复、来源行过长、每张套同一骨架，会让整组卡片像说明书。

| 块 | 规则 |
|---|---|
| 标题 `hd` | ≤8 字，不变 |
| 导语 `lead` | 两行，不变；**人物第一次出现要有名字**，别只写「他」 |
| 正文 `t1` | 一两句人话。**限定默认并进这里**，不带标签：「这是他电脑里算的，没人实测过」「只测了悦耳度，没测不适感」 |
| 限定框 `note` | **整集最多 1 张用**，放最要紧的那条限定，不要每张都有同款框。**健康类安全提醒豁免**，写成 `class="note safety"`，不能删 |
| 来源行 `src` | **一行**，只留「作者 年份」，用 · 隔开：`Schmidt 2001 · Brennan 2024`。期刊、卷期、专利号、括号说明全部移到发布文案「图上数字的出处」表 |
| 收尾句 `final` | 默认不写，见上一节 |

**来源行里原来夹带的限定不能随引文一起丢**：搬进正文，或者放进那唯一的框（示例那条「『同样着迷』是颁奖词，只对疟蚊成立」就是这种）。

下面这些由 `scripts/ai_flavor_check.py` 硬拦：整集多于 1 个 `note`（C1）、`src` 超过一行（C2）。

间距参考（新结构，没有框时）：`t1 = 372 + 图高 + 18`，`src = t1 + 45 × 正文行数 + 24`；有框时 `note = t1 + 45 × 正文行数 + 20`，`src = note + 框高 + 20`。
**第一次用要先出图量一遍**（`node $KIT/scripts/measure_blocks.js 素材/2_answer.html`，块间距 ≥15px），别信公式。

## 出图后人眼必看

门禁（`social-card-qa.mjs`）测不到的清单（前九集踩出来，之后陆续补，序号会变，别在别处写死条数）：

1. **绝对定位块之间叠压** —— 门禁测的是文字行，两个 `position:absolute` 的块压在一起它不报（示例彩蛋踩过）
2. 文字压在右上网点上
3. SVG 主体被画布裁掉（脖子伸太长、身体超出 viewBox）
4. 标注指错了位置（咬痕没落在脚踝上、「蓝光进来」标在右边但光从左进）
5. 同色剪影糊成一坨
6. 图示语义撒谎（刻度不等分、位置暗示了错误因果）
7. 中间大片空白（覆盖率 WARN 只是提示，得自己看）
8. **角色台词替人物下了判断**（角色台词对核查结论下了过强判断，而核查结论是「多因叠加、不判伯努利」）。气泡和群聊里的话也要过「能写 / 不能写」清单，同一个人在正文和群聊里要用同一个名字（正文叫 Schmidt，群聊叫 David，读者会以为是两个人）
9. **表情和动作也会替人物下判断**（示例审稿抓到）：孩子对着妈妈「你出生那天啊……」翻白眼，读起来是嫌烦甚至不孝，等于画面站了队；改成笑着跟着念，梗还在，立场没了。凡是涉及「谁更重要 / 谁更苦」的题，眼神、翻白眼、叹气、捂脸都按台词的标准过一遍
10. **两边的视觉重量要对等**（示例审稿抓到）：两个并排的框，一边有红色大数字、另一边没有，读者会先看数字再得出「那边更大」；两个数字并排（几小时 vs 几年）等于画面自己在比。让两边都有一处同色同号的高亮，或者都不放数字；对仗式小标签（「以小时算 / 以年算」）也一并拿掉

11. **通俗度冷读**：交稿前先**整张放大、逐张看**（不看拼图缩略），假装第一次刷到，写下每张「3 秒读到什么 / 在哪停了一下 / 读成了别的意思吗」；再派一个只看图的冷读 agent。通过线、提示词、八条硬规矩见 `11-通俗度与冷读测试.md`。缩略图会掩盖字太小、图标认不出、物件轮廓易误读等问题。
12. 图里的词和正文是否是同一组词？同一个数字是否一直指同一个对象？跨卡名词、角色和证据边界要保持一致。
13. **有生图主体的卡**：按 12 号文档第八节逐项过——形态（腿 / 触角 / 翅 / 趾，应当为 0 的也要数）、空间与因果、衣襟方向、腿的相位和数量是否与图注一致、物件形制（品牌、伪文字、刻度起点）、伪影（多余肢体、悬空物、像传东西的高光）、画面里的字样、合成后标签有没有盖住关键部位、位图有没有被 `social-card-qa` 漏掉（它只看几何，不看位图里画了什么）；两个独立判读，输出 `报告/考据审查.md`

看完再交给内容负责人。给的是 `_全四张.png` 拼版，不是单张。
