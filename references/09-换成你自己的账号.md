## 怎么设计一个能跨集复用的角色

这是九集里最值的一条经验。

**角色要从账号头像长出来。** `?怪 / !怪` 就是头像的 `?!` 两个符号加上眼睛和腿——
识别度叠加，读者在信息流里看到角色就知道是谁。

**恒定度分层**（哪层能动、哪层不能）：

```
账号名          最难换（改名有冷却期）→ 绑赛道，永不绑单期内容
角色核心图形     高成本 → 符号本身恒定，处理方式（配色/质感）可随集迭代
简介            中成本 → 赛道定位语
主页背景图       低成本 → 当季风格随便换装
每期插画主体     零成本 → 苍蝇、鸡、螺蛳住这层，火了再考虑绑定
```

**抽象主题没有主体可画时**，三个已验证的解法：
1. 把符号本身做成角色（第 3 集：`?!` 当主角）
2. 主体就是内容本身（第 4 集：盯的那个字，拆成部件飞出去）
3. 物件当「刀」（第 8 集：门框把念头泡泡切断）

**角色必须在「做事」**，不能当贴纸。第 3 集初稿角色只是站着，Kai 的反馈是「趣味度还差不少」。

| 1 | 苍蝇 | 复眼 |

## 可以直接拿走、不用改的

- **七步流程**（选题 → 核查 → 结构 → 出图 → 验收 → 文案 → 登记）

- **三层架构**：底图生成 / HTML 文字 / SVG 主体
- **四张图的内容职责**
- **发布后三处登记**
- **九集复盘**里的所有坑

## 换生图服务

`gen_bg.py` 现在打的是火山方舟（ARK）。换别家（Midjourney / SD / 别的 API）都行，
但产出必须满足三条硬规格，否则后面全崩：

1. **2160×2880** 物理像素（不是 1080×1440）
2. **比例精确 0.75**
3. **真 PNG**（魔数 `89504e470d0a1a0a`，不是改后缀的 JPEG）

改法：动 `ARK_ENDPOINT` / `MODEL` / `body`，**保留落盘自验那三道闸**。
prompt 里的固定约束段（零文字、零主体、网点钉右上）照抄，那是实测出来的。
