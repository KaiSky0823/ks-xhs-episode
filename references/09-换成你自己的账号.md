# 09 · 换成你自己的账号

这套流程内含一组冷知识图文视觉示例。方法论和几何规格可复用；发布前应替换成目标账号自己的身份、色板、角色、语气和标签，不要复制示例账号的身份资产。

## 必须适配

| 层 | 当前示例 | 适配方法 |
|---|---|---|
| 账号名称 / 简介 / 赛道 | 生活现象与冷知识 | 换成你的账号定位；定位会影响选题口径与情绪风格 |
| 常驻角色 | 问号、感叹号式几何角色 | 替换 `templates/mascots.py` 的绘制函数，或移除角色层；保持同一角色跨集轮廓稳定 |
| 色板 | 多组浅纸色与强调色示例（见 `08-视觉规范.md`） | 先选纸色和墨色，再选 1–2 个强调色；测 CIE L*、对比度与新旧纸色距离 |
| 文案语气 | 简短、口语、先讲结论 | 以目标账号已发布内容或经授权提供的风格样本校准；不要模仿他人的私人语气资料 |
| hashtag | 原创标签 + 主题词 + 赛道词 | 根据自己的发布数据调整；不要把示例标签照搬为品牌 |
| 平台合规 | 小红书 AI 生成标识 | 按目标平台当前发布界面和现行规则操作 |

## 设计可复用角色

- 从账号识别符或内容机制里提炼简单轮廓；缩到手机缩略图仍要能辨认。
- 将轮廓、眼睛、嘴、腿做成可复用函数，颜色用参数传入，不写死单集色板。
- 角色出现在卡片里要承担动作或读者反应，不只当装饰；站桩和常规眼型可以代码绘制。
- 需要嘴、亲吻或与其他生物互动时，可用参考图生图；结果需逐张检查，参考图不保证每次都稳定。
- 若账号不需要吉祥物，把模板中的主角函数设为自己的角色或移除角色层。

## 可以直接复用的部分

- 八步出一集流程、四张卡职责、事实核查协议和证据强度标注。
- 1080×1440 CSS 画布、2160×2880 底图、比例 0.75、字体与门禁框架。
- 分层制作：底图质感、按需生图主体、代码图示 / 标注 / 数据、HTML 文字。
- 生图的形态、物件、尺度与情绪冷读。

这些是流程能力，不要求每个账号采用相同配色、角色、文风或主题。

## 换生图服务

`gen_bg.py`（底图）和 `gen_art.py`（主体）目前使用火山方舟 Seedream 5.0。替换服务时：

**底图**需满足：
1. 输出物理像素 2160×2880；若服务只能输出较小图，放大后需实测高频细节。
2. 比例精确为 0.75。
3. 输出真 PNG，检查魔数与完整解码。

**主体生图**需支持参考图输入、可抠的纯色背景及 PNG 输出。换模型后重新验证姿态、计数、色板串色、参考图稳定性与后处理边缘，不沿用其他模型的成功率假设。
