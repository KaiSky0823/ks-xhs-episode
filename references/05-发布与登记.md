# 05 · 发布与登记

## 发布前检查

1. **AI 标识**：按目标平台当时的发布界面与适用法规主动声明 AI 生成 / 辅助创作。具体按钮名称可能更新；发布后检查标识是否显示。平台代加标识不应视为可以不主动声明。
2. **顺序**：按钩子 / 答案 / 机制 / 彩蛋顺序检查四张卡。
3. **上传预览**：检查封面裁切、文字是否被遮、缩略图里主题是否清晰。
4. **健康信息**：核对必要的安全提醒和证据边界没有被删。
5. **文案闸**：`04-文案.md` 的句式检查 FAIL 为 0，REVIEW 已处理。
6. **冷读**：`报告/冷读测试.md` 记录通俗度、情绪目标、国别 / 物种 / 物件辨认和不适度；未过的卡先修改。
7. **生图审查**：有生图的卡需完成 `报告/考据审查.md`，形态、方向、物件断言与伪影均过。
8. **评论预备**：准备 AI 标识、证据来源、可能的画面争议和健康边界答复。

## 发布后登记

| 位置 | 记录什么 |
|---|---|
| `$PROJ/选题库.md` | 标题与发布日期 |
| `第N集-XX/发布文案.md` | 实际发布的标题、正文、hashtag；如和稿件不同，记录差异；有生图则记模型、文件、调用次数与审核结论 |
| `$PROJ/发布日志.md`（可选） | 实际曝光表现、读者反馈和复盘问题；若项目有自己的发布登记表，以其为准 |

**实际发布版要记**：标题、正文和标签以发布后的内容为准，不能拿备选稿代表实际版本。评论区对内容清晰度、情绪、事实准确性的反馈可作为下一轮复盘线索；单条反馈不是总体结论。

## 色板登记

每次启用新纸色，将色板名称、PAPER 实测值、CIE L*、INK、强调色、使用集数和与既有色的 ΔE76 写入 `references/08-视觉规范.md`。PAPER 用底图实测值，不用提示词里的标称值；测量方法见 `scripts/measure_bg.py`。
