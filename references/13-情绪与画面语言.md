# 13 · 情绪与画面语言

定方案时先回答：希望读者产生什么情绪？画面靠什么传达？提示词模块见 `../templates/art_prompt_library.md`；冷读方法见 `11-通俗度与冷读测试.md`。

## 证据边界

下面的画面机制来自少量 Seedream 生成候选与**同一模型扮演的模拟读者**冷读，不是真人效果，也不代表跨题材稳定。模拟打分会受批次与对照图影响；只用来定位误读和比较同批候选，不能据绝对分数否决一张看起来成立的图。每次出图都须重新核查事实、形态与读者第一眼理解；最终由使用者看图调整。

## 情绪 → 画面机制

| 目标 | 可尝试的画面机制 | 容易误读的点 |
|---|---|---|
| 浪漫 | 按故事选亲密接触或静止凝视等可见瞬间；按需使用暖色框底与平涂亮边 | 吉祥物围观可能冲淡目标情绪；人物太小可能让关键动作不可辨。小样本不支持为扁平画风设固定的浪漫强度上限，也不能排除风格影响 |
| 好笑 | 一个夸张但和知识点相关的物理结果；身体后弹、瞪眼、张嘴 | 笑点偏离事实，就只是噱头 |
| 敬畏 | 很小的主体对比很大的空间；凝望或停住 | 深色夜空整张生图可能变写实；环境优先代码画在框底，生物另做主体 |
| 好奇 | 局部遮挡、放大圈、主体朝未知处探头 | 身体局部凹陷线条可能产生性暗示或不适；可用小圆点或代码示意 |
| 尴尬共鸣 | 对视又回避、动作不自在 | 侧目与汗滴可能被读成冷战；步相或方向是结论时用代码精确绘制 |
| 温暖 | 被毯子包裹、含泪带笑、大片平涂暖色光 | 只写“温暖”形容词而不改变画面，效果不稳 |
| 惊奇、反转、治愈、紧张等 | 先提出具体构图假设，再小样出图 | 上述机制不能自动迁移；未建立真人受众验证 |

**浪漫封面**按具体故事选择可见关系和构图：托脸、背对、风和暖色亮边只是可选杠杆，不为叠加而叠加。吉祥物是否出现、人物占比及静止或运动都按本题判断；此前模拟冷读不是用户效果数据，也不证明某种组合普遍有效。

**古装国别**可以用经过考据的建筑与环境符号（如白墙瓦檐、月洞门、芭蕉、太湖石）配合服饰，避免单靠朝代标签；重要符号不能被裁掉。模拟冷读中环境线索帮助区分国别，适用范围仅是所试的亲密构图。衣襟方向、服饰和器物真实性仍由独立审稿逐项核，不能用“看起来像中国”代替考据。

## 怎么用

1. 在 `方案_v1.md` 写主情绪、副情绪、出现的卡片和画面动作；厌恶与恐惧写希望控制的方向，不把强烈不适当目标。
2. 生图主体按需写可见瞬间、重心支撑、肢体接触、视线和表情，以及道具状态与结果；静止、等待也可成立。写清裁切遮挡，画外目标预留合成方位；场景、数字、箭头与方向性结论优先代码，场景承担情绪的例外见 `12-生图主体与和谐.md`。
3. 发送前核实际提示词全文与事实、合成方案的正负语义和对位；按当集授权先试 1 张并逐张检查，不把历史 A/B 批数当配额。分别审原图、去底和最终合成，遮挡或画外不能当已验；详见 12 号文档。
4. 不泄露目标给冷读者；记录第一情绪、人物在做什么、误认的国别或物种、不适点。分数是提醒，出现误读就改，没达到模拟阈值但人眼和事实审查通过时可带理由继续。
5. 仅在另有授权做 A/B 时尽量同批、匿名、随机左右；样本小则只说观察到什么，不声称普遍胜率。
