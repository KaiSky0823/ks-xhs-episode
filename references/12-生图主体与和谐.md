# 12 · 生图主体与和谐

本指南处理生动性、准确性和系列风格的分工。公开包只保留方法与通用示例，不附原型账号的历集色板、实验编号或细粒度评分。探索性模拟冷读不是真人效果，不代表全题材验证。

## 一、什么用生图，什么用代码

先问：情绪或信息是否需要表情、姿态、质感承担？需要时尝试生图；不需要时优先代码。再判断三个例外：

1. 姿态、方向、数量本身就是结论：代码控制，不能靠模型碰运气。
2. 物件、液体、气雾、场景、微生物：准确性或透明度优先时用代码。
3. 写实细节会盖过知识、使画面只剩恶心：优先低写实或代码表达。这是画法判断，不按题材或模拟分数自动否决。

| 内容 | 画法与理由 |
|---|---|
| 人物、动物、昆虫 | 生图可以承担表情和姿态；形态、雌雄差异及空间因果仍逐项核 |
| 吉祥物常规表情、站桩、演示 | 代码角色与眼型；需要嘴、亲吻或跨生物互动时尝试参考图生图 |
| 物件、食物、器械 | 代码优先；与人同框生图时核形制、品牌、开口和数量 |
| 液体、泡沫、烟 | 代码半色调优先；确需生图时先试一张，查去背景后的透明度和边缘 |
| 夜空、水下、道路等场景 | 代码放在 `art_frame(scene=...)`，生图主体叠在上面 |
| 微生物、螨、病毒 | 代码放大示意；不把它们画成肉眼可见的虫，不凭空加脸和腿 |
| 无足幼虫、强调「没有某结构」的生物 | 代码优先，模型容易补出不存在的腿、眼或脸 |
| 机制、箭头、剖面、刻度与中文 | 代码，位置、方向和数值必须能核对 |

四张卡按职责决定几张生图，同一张卡可以混合两种画法。主体生成软预算为每集 15 张，超过先与内容负责人复核预算；不是只能有两张卡用生图。

## 二、角色与系列分工

版式骨架、字体、色板、粗轮廓和纸纹保持一致，框内主体按题变化。生图封面大框是正式可选布局，不是每集必用。吉祥物可以当读者替身、引导视线、参与演示或承担喜剧结果；会冲淡目标情绪时不放。

吉祥物不是尺子，没有真实身高。深色主体放深色场景上加纸色外描边；主体、文字和场景的对比度分别验。

## 三、吉祥物参考图工作流

1. 用当集色板和 `templates/mascots.py`、`mascot_ref_example.py` 渲染参考图。示例角色可替换为自己的角色函数。
2. 提示词可选段 ⓪ 描述角色、颜色、眼睛、瞳孔、有没有手和嘴；①–⑤ 五层仍完整保留。
3. 生成与后处理示例：

```bash
python3 scripts/gen_art.py hero_a @第N集-XX/生图/prompt.txt \
  --out 第N集-XX/生图/raw --model flash --size 1536x1536 \
  --image 第N集-XX/ref/mascots_ref.png
```

参考图不能保证造型一致：钩形、眼珠、点与身体的分离、比例、瞳孔数都要逐张检查。多人或跨主体同框不等于已被验证稳定可用。多张参考图的能力与计费以服务商当前文档为准。

## 四、动物、昆虫与其他生物

- 核查结论先列必须画对的结构及来源：腿、触角、翅、趾、鳍、触手、体色、雌雄差异，以及应当没有的结构。
- 提示词④照抄核查结果；不要凭常识编。例如叮人的蚊子不能混用雄蚊羽毛状触角。
- 出图后逐根放大数，并核肢体从哪里长出；「有且只有 N」不是保证。
- 进食、排泄、产卵和叮咬单独核方向、部位与因果。连续三张仍画不对，换视角或用代码，不无限重出。
- 物种本色、白纹、眼白等不在色板时先补进提示词和 `art_grade.py --palette`，不能为统一配色改错物种。

微生物放在放大圈或放大镜中，注明「放大示意」；数量示意不等于可数点阵。螨的结构按具体物种与发育阶段核查，不把所有阶段固定套成同一腿数。

## 五、提示词：五层锚

模板见 `templates/art_prompt.md`，画面模块与整条参考见 `templates/art_prompt_library.md`。

| 层 | 内容 |
|---|---|
| ⓪ 可选参考图段 | 角色造型、当集颜色、眼睛与嘴等 |
| ① 风格 | 扁平、粗轮廓、大色块、半色调阴影，保持系列画法 |
| ② 色板 | 用颜色名，不用 hex 指挥模型；写明主体本色和纯抠像背景 |
| ③ 主体与动作 | 谁、几个、动作、表情；半身/到腰/全身/物件/局部五档构图 |
| ④ 准确性 | 有来源的结构、方向、数量、服饰与道具形制，包含排除项 |
| ⑤ 禁区与部位颜色 | 无文字/水印；按题约束嘴唇、红晕、伤口等，避免强调色串到错误部位 |

人物半身只要求上方和左右留白，底边出血；全身才四周留白。代码主角的 320–400px 不是生图主体的尺寸上限。

浅色主体接近背景时，先试抠像色或 `--no-holes`，检查 mask；抠像色边缘仍可能有色晕，没有全题材验证。情绪画面里的平涂暖边与渐变高光不同，后者不属于本套风格。

提示词长度以清晰和关键项为先。历史 lite 指南的短提示建议不能当成 Flash/Pro 的硬字数上限；过长先删无关修饰，保留④。官方可复现参数以当前接口为准，不假设相同提示词能逐像素复现。

每个构图先出三张，Flash 默认；具体姿势或道具连续失败时再考虑 Pro。提示词写入文件，用 `@路径` 传入，避免 shell 把中文邻接变量解析错。调用 JSON 和选图原因保存在当集目录，不写入 skill 包。

## 六、历史、民族服饰题

服饰极简，环境辅助辨认：月洞门、漏窗、瓦檐与园景等组合线索可能比单独服饰更清楚。别把一个符号视为国别证明，也不要把某组服饰信号的读者联想写成服饰史规律。

人物不能缩成看不见的小点，环境也不能被裁掉。背景若由生图生成，不能用会把环境一起去掉的主体抠图路径；优先代码场景，或按整景合成并重新验画风与文字对比度。

写具体朝代就核具体特征；泛古装不是冒充朝代考据的退路。衣襟方向不靠镜像修正。多个民族并列时优先地图、示意或有依据的对照，避免模型的刻板服饰替代事实。

## 七、流水线

```text
核查结论与画面准确性清单 → 四卡方案、情绪目标与预算
→ 提示词文件 → gen_art → 挑候选 → 两个独立判读
→ art_grade → art_frame / art_sprite 合成
→ QA + 去 AI 味 + 形态/考据 → 冷读 → 内容负责人看图
```

- `gen_art.py` 用 b64 直取，避免图片链接下载失败；网络中断重发可能重复计费，须看重试记录。
- `art_grade.py` 默认 k=16，不保证表情完整；小聚类保护未覆盖所有眼线，必要时补深墨色。主体浅色被挖空时查 mask，再决定 `--no-holes`。
- `art_frame` 五档：`face` 半身、`waist` 到腰、`full` 全身、`object` 物件、`closeup` 局部。focus 只按半身人脸设计，其他主体不要硬套。
- 场景在主体下方，标注在纹理上方；深底加 `outline`，并先预览抠图碎点，不能靠描边掩盖残渣。
- `art_sprite` 缩小复用主体，不带框；纸纹遮罩需内联 data URI，不能依赖会静默失效的本地文件遮罩。
- 纸纹沿画布坐标对齐；封面大框由 `COVER_ART` 选择，`COVER_EYES=None` 可不显示封面吉祥物。

## 八、形态、考据与画面断言审查

使用 `templates/考据审稿_prompt.md`；两个审阅者与生成/挑图者独立，分歧交内容负责人裁定。输出 `报告/考据审查.md`。

1. 数结构和手指，核物种、雌雄、方向与部位。应当为零的结构也要查。
2. 服饰逐人放大；先旋转到正向，不能镜像。领口交叉点看线条连续与遮挡，不凭宽窄猜。
3. 提示词和核查结论未提的具体场景、器物、接触和旁观者，逐项视作新的画面断言。
4. 图与引用原文的动作、场合和意思一致；不能把「没有发生」画成「已经发生」。
5. 手机缩略图复看物种、国别与时代联想；少于三位独立读者只触发复核，三位以上且至少三分之二误读时按辨认未过处理。联想不替代史实核查。
6. 查悬空物、粘连肢体、重复瞳孔、伪文字和接触点伪影。
7. 物件核型号类别、开口、刻度起点、品牌、数量与高度；这些都可能是断言。

几何 QA 不会判断所有位图内容，人眼与准确性审查不能省。

## 九、预算与时间

开工前写生图预算：底图次数 + 构图数 × 每批候选数 × 预计批数。另算每张生图卡的两个独立审阅和冷读，不只算图片 API。

价格、参考图收费、输出像素上限和模型状态以方舟当前文档为准，见 07；不要把旧批次耗时或可用率当成服务保证。连续失败先改画法，超过主体软预算先复核，不自动无限重试。

## 十、底图与纸色

Flash 为默认，`gen_bg.py --paper '#RRGGBB'`：模型出近白质感，`tint_bg.py` 事后上色；最终须为 PNG、2160×2880、比例 0.75、L*>92。网点左缘以当图实测为准，不用旧固定坐标。

先用 `pick_paper.py` 选满足 ΔE≥8 的新色。没有合格新色时可复用已登记明亮旧色，另换强调色和构图并登记：

```bash
python3 scripts/measure_bg.py 第N集-XX/素材/tex_demo.png \
  --reuse-paper '#FAF5E7' --reuse-reason '使用不同强调色与构图，已在方案登记'
```

示例色号必须已在你的色表登记；复用通道只豁免新色差异要求，不能绕过明度、目标匹配与色表读取检查。公开色表是合成演示，不是你的真实发布历史，开始制作时换成自己的登记。

## 十一、证据边界与未验证项

流程的分工与若干情绪模块做过探索性样例，但不是真人效果或全题材通过证据。跨集角色稳定性、多张参考图、浅色主体抠像边缘、非人物大框、不同民族服饰及所有真实场景，仍需逐题验证。模板合成成功不等于某个题目的情绪与事实都过关。

## 十二、尺度与创作判断

大胆创作，不因普通笔记规则全文未取得而整体暂停或降低表达。保留事实、形态、可读性与基本安全审查；不做未成年人性化、露骨性行为、血腥伤害猎奇或鼓励危险模仿。

排泄、医疗、身体、虫类和酒类可按知识目的正常表达；具体疑点写出「哪一处会被看成什么」，选择代码、低写实或重新构图，不按题材一票否决。成年人正常亲吻可以按情绪需要画。

恶心≤5、害怕≤3、不适度≥6是复看提醒，未经真人标定，不因模拟分数自动毙稿。完成后由内容负责人看图，觉得尺度不合再调；不保证平台通过。商业审核摘要、自然笔记与 AI 标识的证据边界见 `14-平台尺度与AI标识.md`。
