# 11 · 通俗度硬闸与冷读测试（含第三道：情绪对题）

本文件把通俗度、理解准确度、情绪对题和不适度变成独立检查点。写作者容易因为已经知道背景而高估读者理解，因此冷读者不得先看事实盒或方案。

## 反例：比喻、术语和限制同时挤进一张卡

| 卡片位置 | 常见问题 |
|---|---|
| 封面 | 用比喻代替主题，核心话题词只放在小字里；读者要先解谜才知道内容 |
| 答案 | 比喻、术语、研究限制同时堆叠，导致主结论埋在正文里 |
| 数据 | 百分比、样本数和统计限定并排，没有一句普通读者能直接复述的人话 |
| 彩蛋 | 标题说研究设计，不说结果；限制写成论文句 |

**处理原则**：证据边界要守，但用读者听得懂的人话守；每张卡先给结论，再给一个必要限定。

## 一、通俗度硬规矩（出图前自查；一条不过不给本人看）

1. **封面 3 秒自解释。** 封面只靠「人人经历过的瞬间 + 话题词放大字 + 一句人话」，**不用比喻**。话题词（读者搜的那个词）必须在大字里。
   比喻可以出现在后面的卡里，但不能由比喻承担第一屏的信息。
2. **一张卡一个要点，要点进导语。** 读者只读标题和导语两行也要拿到这张卡的结论；正文是补充，不是答案。
3. **术语最多一个，当场用人话解释；图里的词和正文用同一组词。** 一次冷读反例 ② 图里画「吓到」、正文写「被摸」，读者以为是两件事。
4. **数字翻成人话，且一张卡不超过 5 个不同的数字。** 「N 段 / N 个人 / 10 次里 6 次」优先于百分比；别出现「百分比的百分比」「X% 的片段」这类要二次换算的写法。
   两个数字并排时要想清楚读者会不会串（一次冷读反例 ③ 的「18 段」和 ④ 的「18 个人」不是同一个 18）。
5. **限定写成短人话，别写成论文句。** 限定要保留（核查的成果），但长度压到一句、用词压到初中生能懂。见下表。
6. **图里的字块要少。** 每张卡图内标签（不含数字和点阵）控制在 6 到 8 处；副标签、括号、「日常说法」这类要读者停下来想的注释，能砍就砍。
7. **图和字谁也不能单独挑大梁。** 遮住图只看字，能懂这张卡说什么吗？遮住字只看图，能猜到话题吗？两个都不行就是没过。
8. **整集要有一句话结论。** 四张读完，读者能不能一句话复述「这集说了什么」？说不出来，说明三四个小结论之间没有「所以」，要么删一个，要么补一句连接。

## 二、论文口径 → 人话（通用改写）

| 论文口径（不要） | 人话（要） | 为什么 |
|---|---|---|
| 「N 段里 M 段出现某现象」 | 「M 段出现了」 | 先说读者关心的现象；统计单位要明白 |
| 「所占比例约为 11%」 | 如果比例不是核心结论，就删掉或写进出处表 | 避免让读者做二次换算 |
| 「参与者的数据合并分析后」 | 「把 N 个人的结果放在一起看」 | 避免「合起来」被误读为平均或人人都如此 |
| 「实验环境未严格控制」 | 「测试时没有严格控制环境」 | 保留限制，用短句写 |
| 「未能给出合理估计」 | 「目前没法估计有多少」 | 避免把统计术语堆在图上 |
| 「上游的通路不同，末端效应相同」 | 「起因不同，最后动手的是同一环节」 | 把隐喻链缩成一个明确机制 |
| 学名或专门术语（图里） | 图上用常用词，正文首次出现时补学名 | 术语只放在读者需要它的位置 |

## 三、检查点 A：自己整张放大逐张冷读（每次交稿前，必做）

不看拼图缩略。**一张一张、整张放大看**，假装第一次刷到，不知道任何设定，边看边写下：
1. 3 秒内我读到了什么？一句话。
2. 我在哪个词、哪个图标、哪个括号上停了一下？
3. 我读成了和我想说的不一样的意思吗？
4. 这张我会继续往下滑吗？

拼图缩略会掩盖字太小、图标认不出、物件形状容易误读等问题；每张必须整张放大检查。

## 四、检查点 B：冷读 agent（每集交稿前，必做，一轮）

派一个**只看图、不知道任何设定**的独立冷读者；**只给它四张图，不提供方案或事实盒**，避免诱导。
它和 `04-文案.md` 里的「审稿 agent」不同：审稿 agent 找句式 AI 味，冷读 agent 测**懂不懂**。两个都要。

提示词模板（派单时**不要在 prompt 里写目标情绪**，写了就是诱导；**每个冷读 agent 只给一个候选，且不要在它的第一部分里放对照图**）：

```
你是一个第一次刷到这篇小红书冷知识图文的普通读者（28 岁，文科背景，没学过<相关学科>，不认识作者，也不知道账号背后的任何设定）。
请只凭图本身做判断。不要读取方案、事实盒或项目里的其他资料；只查看下面四张图，不进行网络检索，不使用需要登录态的浏览器资料，不修改其他文件，只写下面指定的输出文件。

用 Read 逐张看（每张 2160×2880，请整张放大看，包括小字）：<四张图的绝对路径>

任务：测「通俗易懂」。每张图分别回答：
(a) 3 秒内你读到了什么？一句话说出这张在讲什么（凭第一感觉，不要事后推理）。
(b) 哪些词、哪句话、哪个画面你要停下来想一想才明白，或者根本没明白？逐条列：位置、你卡在哪、你猜它想说什么。越具体越好，包括图里的小字、标签、图标。
(c) 有没有哪里你读成了和作者想的不一样的意思？
(d) 这一张你会不会继续往下滑？为什么。
(e) 这张图让你的第一情绪是什么？只写一个词，再从这些里选最接近的（可多选）：搞笑 / 可爱 / 浪漫 / 甜 / 尴尬 / 神秘 / 严肃 / 恶心 / 害怕 / 惊讶 / 温暖 / 好奇 / 共鸣（原来如此）/ 敬畏 / 被打脸（原来我信错了）/ 安心 / 其他（写出来）。
(f) 这个情绪的强度，0 到 10（0 = 没有，10 = 非常强），一句依据。
(g) 图里的人物或角色在做什么？一句话，不要靠标题推。
(h) 画面里的人物、服饰、道具或环境符号让你联想到哪个国家 / 时代？写第一印象，不确定就说不确定；没有相关线索就写「无」。
(i) 有没有被逗笑？0 到 10，笑在哪里。
(j) 画面里有动物、虫子、其他生物，或者你认不出的物件的话：你认得它是什么吗？写名字，不确定就说不确定。它身上有没有哪里看着不对劲（腿或触角多了、手指数不对、东西悬空、两个东西粘在一起、像某个牌子）？都没有就写「无」。
(k) 这张图让你不舒服吗？0 到 10。会不会因此直接划走？具体哪个画面让你不舒服？不预测平台是否限流。
最后（**单张候选变体**：只测一张封面候选时，删掉第 1 题和第 5 题里「整套」的部分，并在 (a) 前写明「这是一篇笔记的封面」）：1. 四张连起来你能用一句话复述这集的结论吗？写出来。2. 最难懂的 3 个地方，按难度排序。
3. 只许改 3 处让它更通俗，改哪 3 处？给出替换文字或画面改法。4. 整体「通俗度」打分（1 到 10，10=初中生一眼就懂），说明依据。
5. 整套的情绪：封面和整套各给一个词、一个强度。
你的所有判断都是推断，请标明。不要夸，不要客气。
输出文件：<报告/冷读测试.md 的绝对路径>
```

### 怎么用结果

- **通过线**：通俗度 ≥ 7，且四张的「3 秒读到什么」都和想说的一致，且能一句话复述结论。过不了就改，别交稿。
- **情绪目标与提醒**：主情绪应能读出，动作不能被读错；强度≥7是创作目标，不因模拟分数单独判不通过。反转情绪看指定卡位。未达预期时查画面原因，不仅改标题；具体疑点与修改后是否复测记入方案。
- **不适度复看提醒**：(k)≥6 或有人说会划走时，查具体误读和观感，不按模拟分数一票否决；有问题先按题调整画法，成稿交内容负责人看图。
- **国别 / 时代误读**：少于三位独立读者只触发复核；至少三位且≥2/3误读，按辨认未通过处理。联想不是史实证明，具体服饰与时代仍按核查结论审。
- agent 给的替换文字是按所见内容拟的，采纳前要对照核查结论；不能把未经核实的限定补进文案。
- 冷读原文放 `报告/冷读测试.md`，处理记录和「改完后是否重新测试」写进当集 `方案_v1.md`（模板 `templates/方案.md`）。没测最终版就明确写未测。
- 模拟读者不是真读者。它的分数用来比较（改前改后），不当作绝对值。

### 一致性测试（单独一个 agent，不和冷读混用）

需要测系列一致性时要**盲测**：把候选与已发布图打乱、匿名，问哪张最不像同一系列；另加一组已发布图之间的对照，估计读者本身的分歧。**一致性测试与单张冷读分开跑**，避免读者先看过候选而认出它。

## 五、脚本能帮多少（`scripts/ai_flavor_check.py`）

只加了两条 REVIEW（不拦出图）：
- **V13 疑似论文腔 / 术语**：命中「口径、分母、显著、样本、受试、对照、变量、组水平、合起来看、严格控制、合理的估计、量表、统计、参与者、机制」等词。
- **V14 单卡数字太多**：一张卡里不同的数字（不含年份）≥ 6 个。

它抓不住「比喻太绕」「逻辑链长」「图标认不出」这三样，那三样只能靠检查点 A 和 B。试过「图内字块 > 12 处」当规则，和画面好坏对不上（第二版 ② 是 10 处，第三版 ③ 是 11 处），已撤。

## 六、整条流程里放在哪

`SKILL.md` 七步里的第 5 步「人眼验收 + 给本人看」前面插入：**检查点 A（自己冷读）→ 检查点 B（冷读 agent）→ 改完 → 再给本人**。
文案阶段（第 6 步）的发布文案、评论预备同样适用本文件第一、二节：回复里也不要出现术语和论文句。

## 七、情绪对题（第三道硬闸）

**适用原因**：通俗度 / 笑点冷读不能代替情绪测量。每个检查点只覆盖它实际提出的问题；没有直接询问目标情绪，就无法判断画面是否表达了目标情绪。

规矩：

1. **定结构时先写「情绪目标」**（`SKILL.md` 第 2 步）：主情绪（一个词）＋ 副情绪（可空）＋ 每个情绪的方向（≥ 几 / ≤ 几）＋ 出现在哪张卡，写在 `方案_v1.md` 最上面（字段格式见 `templates/方案.md`）。词表：搞笑 / 尴尬共鸣 / 原来如此 / 好奇 / 惊讶 / 敬畏 / 浪漫 / 温暖 / 打脸（被骗了一下）/ 恶心（上限）/ 害怕（上限）。复合情绪（浪漫为底、轻恶心为钩）拆成主、副两个写；先吓后收的题，反转情绪写在 ②；同时写「画面能不能承担它」：吉祥物的表情和动作够不够？不够就在这一步决定换画法（见 `12-生图主体与和谐.md`），**不要画完再发现**。
2. **冷读模板里的 (e)(f)(g)(h)(k) 五问不能删**（第一情绪、强度、在做什么、像哪国哪朝、不适度），而且**不告诉 agent 目标情绪**（告诉了就是诱导）。
3. **目标情绪与动作**：主情绪应能读出，动作应答对；强度是辅助读数，不自动否决。浪漫、温暖、敬畏等已有探索性模拟样例，不能把首轮最高分当画风天花板，也不能把样例分数当真人效果。
   **复看提醒**：恶心≤5、害怕≤3是未真人标定的工作参考，不是超过即判不通过；按实际画面、事实和知识目的决定，再交内容负责人看稿。
4. **情绪不清先改画面**：调整姿态、尺度、构图或代码/生图分工；不要只改标题宣称已经有目标情绪。数值偏离触发复看，不自动要求重出。
   换画法不等于换掉账号风格：先调姿态、主体面积、视线、框形和局部色光；不要未经对照就认定画风造成上限。
5. 冷读报告表头加四列：目标情绪（主 / 副 / 反转，带方向）/ 冷读读到的情绪 / 强度 / 不适度 (k)。每一轮都填，改前改后并排看。
