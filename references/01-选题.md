# 01 · 选题

## 选题库在哪

`$PROJ/选题库.md` 是唯一事实源（`$PROJ` 见 00 号文档；带编号的候选索引是 `$PROJ/候选清单_编号版.md`）。结构：

- 顶部：已发布的集，按集数排，每集一段（主线 + 关键事实表 + 不能写）
- 中部：**待孵化**，按入库批次分节
- 末尾：规矩那一行

每集发布后必须回来把状态改成「已发布」，**当场改，别攒**。

## 什么算好选题

按「共鸣 × 有研究 × 有反转 × 主体可画」四项打分。

### 共鸣（权重最高）

读者的第一反应必须是「**对！我也这样！但我从没想过为什么**」。
不是「哇涨知识」，是「这也太懂我了」。

已验证有效的共鸣类型：
- 人人经历过但没名字的（进房间忘事、盯字变陌生）
- 人人吐槽过的（蚊子咬脚踝、泼不中苍蝇）
- 天天吃/天天见但没想过的（螺蛳、鸽子）
- **当场能验的**（盯字 26 秒、看蓝天、按住一边鼻孔）← 参与感最强，优先

### 有研究

必须有**有名有姓的研究**能支撑。判断：
- 找得到作者 + 年份 + 期刊 → 可做
- 只有科普站/百科 → 降级，机制可以讲但不能说「某某研究发现」
- 只有品牌委托调查、自媒体文章 → 不能当科学依据，但**可以当被拆穿的对象**（示例的 72% 就是这么用的）

### 有反转

排序：
1. 流行解释被推翻（洗澡、鸽子点头、门口效应）
2. 民间对策没用（走回去也想不起来）
3. 数据和直觉相反（躺下后脸就是脚踝）
4. 只是「原来有名字」（次一档，但配上参与感也能成）

### 主体可画

优先有具体物件、身体部位、动物。
**「可画」拆三档评，入库时写在风险栏**：
- **代码可画**：图示、身体部位、物件、场景、微生物、吉祥物站桩或演动作。最稳，成本只有底图。
- **生图可画且过闸**：人物、动物、昆虫要靠表情姿态才成立，且形态有出处可抄、过得了形态 / 考据审查（12 号文档；古装和非中国服饰风险高，无足幼虫、方向或数量就是结论的题不算这一档）。成本见 12 第九节公式。
- **有尺度风险**：排泄、伤口 / 医疗、昆虫密集、身体暴露、酒类、健康恐惧（12 号文档第十二节「尺度与创作判断」）。不是不能做；风险栏写明碰到哪一行，由内容负责人按证据和受众决定是否调整评级。
选题名本身是比喻的（「微型雨林」「它在吃你」「夜聊」），风险栏写「标题是比喻，封面要改字面」（03：封面不用比喻）。
**抽象主题不是不能做**，但要先解决「画什么」：
- 示例：没有生物 → 把账号头像的 `?!` 做成角色
- 示例：主体就是那个字本身，拆成部件飞出去
- 示例：门框当「刀」，念头泡泡被切断

## 排期纪律

- **别连做同一类**。动物连做三集（蚊子/螺蛳/鸽子）之后必须换。
  类型轮换：动物 → 身体感知 → 心理认知 → 生活物件。
- **同一个身体部位隔几集再碰**（痒、蚊子包、挠都是「痒」家族）。
- 被插队的选题在库里标「顺延为第 N 集」，别让它消失。

## 新选题从哪来

1. **创作者的真实观察** ← 自带具体困惑
2. 读者 / 同行提出的生活问题
3. 全网搜刮：派四路 agent 分头搜（中文社区共鸣型 / 英文社区高赞 / 身体感知研究底座 / 生活物件类），
   要求每条给「现象一句话 / 共鸣点 / 研究线索 / 反转点 / 主体可画 / 中文适配度」，最后各自排前五。
   **搜回来的要自己抽查**：2026-09-20 那轮里，agent 报的「2025 年验证睁眼打喷嚏眼球不会掉」疑似编造，
   「东京大学 2008 狗打哈欠」记错了机构（实为伦敦大学 Joly-Mascheroni）。

## 入库怎么写

一条至少包含：现象一句话、研究底座（作者+年份+期刊，或「查无」）、反转点、风险/备注。
**风险那一栏最值钱**，它决定开工时会不会翻车。
