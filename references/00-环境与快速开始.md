# 00 · 环境与快速开始

**目标：拿到这个 skill + 自己的 API key，半小时内跑出第一张合格的图。**

---

## 1. 装环境（装一次，之后不用管）

### Node（出图 + 门禁）

```bash
cd "$HOME/skills/ks-xhs-episode"   # 若安装在别处，将路径改成实际 skill 目录
npm i playwright            # 不必 npx playwright install，用系统 Chrome
```

脚本优先用系统装的 Chrome（`chromium.launch({ channel: 'chrome' })`），
启动失败才回落到 playwright 自带的 chromium。**推荐装系统 Chrome**——
playwright 自带的那个放在 `~/Library/Caches/ms-playwright`，实测会被周期性清掉，
依赖它等于让工具随机失效。

### Python

```bash
pip install -r requirements.txt     # pillow numpy opencv-python scikit-learn
```

`gen_bg.py` / `gen_art.py` 只用标准库 + Pillow；`measure_bg.py` 要 numpy；`art_grade.py`（生图主体去背景 + 调色）要 opencv-python 和 scikit-learn。

### 字体（中文不出错的前提）

需要 **Noto Sans CJK SC** 和 **Noto Serif SC**。

```bash
# macOS
brew install --cask font-noto-sans-cjk-sc font-noto-serif-sc
# 验证（某些系统没有 fc-list；用已安装的 Playwright 浏览器运行下面的 node 脚本）
node scripts/_fontcheck.mjs
```

⚠️ **别用 `fc-list` 查**——有些环境没装 fontconfig，`command not found` 会被
`2>/dev/null` 吞掉，看起来像「字体没装」。

**DNA 禁止 `@import` 和 webfont**：必须用本机已装字体。否则截图会拍到 fallback 字形，
而门禁是等 `document.fonts.ready` 的——门禁过了、截图却是错字形，最难查。

### API key

```bash
export ARK_API_KEY='YOUR_API_KEY_HERE' # placeholder: replace with your own key
```

火山方舟（ARK）控制台申请，开通 **`doubao-seedream-5-0-flash-260915`**（底图和生物主体默认都用它）；
可选开通 `doubao-seedream-5-0-pro-260628`（道具、姿势反复画错时换用）。lite（`…-lite-260128`）官方已标「即将下线」，只有 `gen_bg.py --engine lite` 才需要。
**换别家生图服务也行**，但要改 `gen_bg.py` / `gen_art.py` 的 `ARK_ENDPOINT` / 模型 / 请求体，
并保证底图产出满足三条硬规格：**2160×2880、比例精确 0.75、真 PNG**；生物主体的服务还要支持参考图输入。详见 `07-底图与生图API.md`、`09-换成你自己的账号.md`。

### 约定的目录布局

下文命令里：`$KIT` = 本 skill 的目录（例如 `$HOME/skills/ks-xhs-episode`，或你 clone 的位置）；`$PROJ` = 放各集目录的父目录（和 `$KIT` 平级即可）。
先在当前 shell 设置：
```bash
export KIT="$HOME/skills/ks-xhs-episode"   # 如果装在别处，就改为实际路径
export PROJ="$HOME/xhs-project"                    # 改成你的工作目录
```
**所有命令都在 `$PROJ` 下执行**，脚本用 `python3 "$KIT/scripts/xxx.py"` 调用，集目录用相对路径 `第N集-XX/...`。
选题库放 `$PROJ/选题库.md`，带编号的候选索引放 `$PROJ/候选清单_编号版.md`（没有就新建，见 `01-选题.md`）。

## 3. 跑通第一张图（五条命令，cwd 在 `$PROJ`）

```bash
# ① 挑纸色 + 生底图（每集固定的一次底图调用，默认 Flash；颜色由脚本事后落到你挑的 hex）
export ARK_API_KEY='YOUR_API_KEY_HERE' # placeholder: replace with your own key
python3 $KIT/scripts/pick_paper.py                  # 列出还没用过的纸色（第三方第一次用：已用纸色表就是 08 里那张，可以清空自己的）
python3 $KIT/scripts/gen_bg.py --paper '#B8FEF4' -o 第1集-试/素材/tex_test.png
#   模型只出近白质感 + 深色粗网点；脚本把纸色 / 网点色落到 --paper，原图另存 *_src.png；落盘自验 L* > 92、尺寸、比例

# ② 测实测均色 + 对已用纸色算 ΔE → 把输出的 hex 填进 build 脚本的 PAPER
python3 $KIT/scripts/measure_bg.py 第1集-试/素材/tex_test.png

# ③ 复制模板 + 占位角色，改成当集的
cp $KIT/templates/build_ep_template.py 第1集-试/build_ep1.py
mkdir -p 第1集-试/素材/svg
cp $KIT/templates/svg示例/主角占位.svg 第1集-试/素材/svg/主角.svg
#   改 build 脚本里：BG 文件名、PAPER/INK/ACCENT、load_svg('主角.svg')、四张的文案
#   占位角色跑通后换成你自己画的，见 08-视觉规范.md §6
#   有生物 / 人物的卡：吉祥物参考图 → gen_art.py → art_grade.py → art_frame() 合成，见 12-生图主体与和谐.md 第三、七节

# ④ 出 HTML → 截图（文件名必须是 1_cover … 4_egg，去 AI 味闸只认这四个名字）
python3 第1集-试/build_ep1.py
node $KIT/scripts/shot.js 第1集-试/素材/1_cover.html 第1集-试/1_cover.png 1080 1440

# ⑤ 过门禁（exit 1 就是不合格，不要肉眼放行）
node $KIT/scripts/social-card-qa.mjs 第1集-试/素材/1_cover.html
```

四张各跑一遍 ④⑤。**exit 0 且 0 WARN 才算过。**

## 4. 门禁在查什么

`social-card-qa.mjs`，十条规则：

| 规则 | 查什么 |
|---|---|
| R1 溢出 | 内容超出画布 |
| R2 底部碰撞 | 与底部固定元素重叠 |
| R3 越界 | 元素越过画布边界 |
| R4 行墨迹碾压 | 相邻行**字形**重叠（不是行盒）；不透明块盖住别行的字 |
| R5 最小字号 | < 16px 手机上不可读；< 24px 正文吃力（WARN） |
| R6 字体降级 | 拍到了 fallback 字形（FAIL） |
| R7 模板变量泄漏 | `{{ }}`、`<一句…>` 这类占位符没替换 |
| R8 内容覆盖率 | < 35% 画面显空（WARN，克制型构图可豁免） |
| R9 资源缺失 | 底图、生图主体、`<img>`、SVG `<image>` 加载失败（FAIL） |
| R10 文字对比度 | 文字压着的背景对比不够：**字压在位图（生图 / 照片）上且 < 2 → FAIL**；其余 < 3（含代码里写死颜色、故意做淡的印章 / 水印 / 幽灵字）→ WARN，每张汇总一条，人眼确认是有意淡化就放行 |

**门禁测不到的事必须人眼看**，清单在 `03-四张图.md` 末节（含生图专项）。位图里画了什么（伪影、字样、形态、方向）门禁一概不管，靠 12 号文档第八节的审稿。

另有一道**文字闸**，和几何门禁分开跑（只要 python3，不需要 playwright）：

```bash
python3 $KIT/scripts/ai_flavor_check.py 第1集-试/素材/[1-4]_*.html 第1集-试/发布文案.md
```

查图上字和发布文案里的句式层 AI 味，exit 1 不交付。**`shot.js` 已把它前置**：定稿卡（`素材/[1-4]_*.html`）出图前自动跑一遍，没过就不出图；仅预览可设 `SKIP_FLAVOR_GATE=1`，预览图不得交付。规则和后三步见 `04-文案.md`「去 AI 味硬闸」。

## 5. 常见报错

| 症状 | 原因 / 解法 |
|---|---|
| `gen_bg.py` / `gen_art.py` 说没有 key | 当前环境没有设置 `ARK_API_KEY`；先按安装说明 export API key |
| ARK 返回 400 / 404 模型不可用 | 方舟控制台没开通 Flash（或 Pro）；只开了 lite 不够 |
| 响应读到一半断开（`IncompleteRead`） | 脚本自动重试 3 次；**重发可能重复计费**，看 json 里的 attempts |
| `gen_bg.py` 报纸色 L* ≤ 92 | 用 `--paper '#RRGGBB'`（先 `pick_paper.py` 挑一个 L* > 92 的）；不加 --paper 靠提示词碰色，Flash 会出偏深或偏白的纸 |
| `gen_bg.py` 说 Flash 回的尺寸和请求不一致 | 服务端行为变了，不要强行放大，先看 12 号文档第十节 |
| 落盘的不是真 PNG | 服务端返回了 JPEG。检查请求体有没有 `output_format: "png"` |
| 比例不是 0.75 | 改 `size`。比例错会让右上网点被静默裁掉 |
| 截图字体不对 | 中文字体没装，或 HTML 里用了 `@import`/webfont（DNA 禁止） |
| 门禁 R6 报字体降级 | 同上 |
| `shot.js` 说「定稿卡必须命名为 1_cover…4_egg」 | `素材/` 下的 html 命名不对，去 AI 味闸会被绕过，所以拦下来；预览设 `SKIP_FLAVOR_GATE=1` |
| `art_grade.py` 警告内部有洞 / 小聚类被吸掉 | 见 12 号文档第七节三个已知坑 |
| `shot.js` 起不来 | 装系统 Chrome，或 `npm i playwright` |
| 导入 build 脚本就长出空 `素材/` 目录 | 模板里 `OUT.mkdir()` 已挪进 `__main__`，别挪回模块顶层 |
