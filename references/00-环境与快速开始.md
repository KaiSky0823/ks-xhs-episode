# 00 · 环境与快速开始

**目标：拿到这个 skill + 自己的 API key，半小时内跑出第一张合格的图。**

---

## 1. 装环境（装一次，之后不用管）

### Node（出图 + 门禁）

```bash
cd <skill 目录>
npm i playwright            # 不必 npx playwright install，用系统 Chrome
```

脚本优先用系统装的 Chrome（`chromium.launch({ channel: 'chrome' })`），
启动失败才回落到 playwright 自带的 chromium。**推荐装系统 Chrome**——
playwright 自带的那个放在 `~/Library/Caches/ms-playwright`，实测会被周期性清掉，
依赖它等于让工具随机失效。

### Python

```bash
pip install pillow numpy
```

`gen_bg.py` 只用标准库 + Pillow；`measure_bg.py` 要 numpy。

### 字体（中文不出错的前提）

需要 **Noto Sans CJK SC** 和 **Noto Serif SC**。

```bash
# macOS
brew install --cask font-noto-sans-cjk-sc font-noto-serif-sc
# 验证（mac mini / 某些环境没有 fc-list，用下面的 node 脚本代替）
node scripts/_fontcheck.mjs
```

⚠️ **别用 `fc-list` 查**——有些环境没装 fontconfig，`command not found` 会被
`2>/dev/null` 吞掉，看起来像「字体没装」。

**DNA 禁止 `@import` 和 webfont**：必须用本机已装字体。否则截图会拍到 fallback 字形，
而门禁是等 `document.fonts.ready` 的——门禁过了、截图却是错字形，最难查。

### API key

```bash
export ARK_API_KEY=<你自己的 key>
```

火山方舟（ARK）控制台申请，开通 `doubao-seedream-5-0-lite-260128`。
**换别家生图服务也行**，但要改 `gen_bg.py` 的 `ARK_ENDPOINT` / `MODEL` / 请求体，
并保证产出满足三条硬规格：**2160×2880、比例精确 0.75、真 PNG**。详见 `07-底图与生图API.md`。

## 3. 跑通第一张图（五条命令）

```bash
# ① 生底图（唯一的 API 调用）
export ARK_API_KEY=<你的 key>
python3 scripts/gen_bg.py -o 第1集-试/素材/tex_test.png \
  "极浅裸粉色纸面，接近 #FCEADF 的暖粉白，纸浆纤维清晰，轻微折痕与泛旧，半色调网点为深橄榄绿色"

# ② 测实测均色 → 把输出的 hex 填进 build 脚本的 PAPER
python3 scripts/measure_bg.py 第1集-试/素材/tex_test.png

# ③ 复制模板 + 占位角色，改成当集的
cp templates/build_ep_template.py 第1集-试/build_ep1.py
mkdir -p 第1集-试/素材/svg
cp templates/svg示例/主角占位.svg 第1集-试/素材/svg/主角.svg
#   改 build 脚本里：BG 文件名、PAPER/INK/ACCENT、load_svg('主角.svg')、四张的文案
#   占位角色跑通后换成你自己画的，见 08-视觉规范.md §6

# ④ 出 HTML → 截图
python3 第1集-试/build_ep1.py
node scripts/shot.js 第1集-试/素材/1_cover.html 第1集-试/1_cover.png 1080 1440

# ⑤ 过门禁（exit 1 就是不合格，不要肉眼放行）
node scripts/social-card-qa.mjs 第1集-试/素材/1_cover.html
```

四张各跑一遍 ④⑤。**exit 0 且 0 WARN 才算过。**

## 4. 门禁在查什么

`social-card-qa.mjs`，八条规则：

| 规则 | 查什么 |
|---|---|
| R1 溢出 | 内容超出画布 |
| R2 底部碰撞 | 与底部固定元素重叠 |
| R3 越界 | 元素越过画布边界 |
| R4 行墨迹碾压 | 相邻行**字形**重叠（不是行盒）；不透明块盖住别行的字 |
| R5 最小字号 | < 16px 手机上不可读；< 24px 正文吃力（WARN） |
| R6 字体降级 | 拍到了 fallback 字形 |
| R7 模板变量泄漏 | `{{ }}` 没替换 |
| R8 内容覆盖率 | < 35% 画面显空（WARN，克制型构图可豁免） |

**门禁测不到的七件事必须人眼看**，清单在 `03-四张图.md` 末节。

## 5. 常见报错

| 症状 | 原因 / 解法 |
|---|---|
| `gen_bg.py` 说没有后端 | 没设 `ARK_API_KEY` |
| 落盘的不是真 PNG | 服务端返回了 JPEG。检查请求体有没有 `output_format: "png"` |
| 比例不是 0.75 | 改 `size`。比例错会让右上网点被静默裁掉 |
| 截图字体不对 | 中文字体没装，或 HTML 里用了 `@import`/webfont（DNA 禁止） |
| 门禁 R6 报字体降级 | 同上 |
| `shot.js` 起不来 | 装系统 Chrome，或 `npm i playwright` |
| 导入 build 脚本就长出空 `素材/` 目录 | 模板里 `OUT.mkdir()` 已挪进 `__main__`，别挪回模块顶层 |
