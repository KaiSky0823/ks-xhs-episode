# 生图提示词库

先在 `references/13-情绪与画面语言.md` 选画面机制，再按 `art_prompt.md` 的五层拼接。这里保留通用模块与适配后的示例，不附账号实验编号和细粒度读数；改写示例没有逐条复测，不能当成功率保证。所有形态、数量与历史特征仍须有核查依据。

## 一、共同风格与配色

```text
扁平矢量插画，丝网印刷风格，粗而均匀的深墨色轮廓线，大色块平涂，阴影只用半色调网点，没有渐变、没有写实质感。
只用这几种颜色：【当集色板的颜色名】。主体背景为纯色【主体不会使用的抠像色】，没有纹理、文字和景物。
```

模型提示用色名，hex 留给代码与后处理。补足眼白、物种本色和必要的深墨色，避免调色把关键细节吸掉。暖色框底由代码生成，不把浅肤色背景同时当抠像色；脸和手是否被挖空，要看 mask，必要时 `--no-holes`。

强调色可能串到脸颊、嘴唇或叮咬点：按部位明确颜色。平涂暖边允许作为局部大色块，不用渐变或写实高光。

## 二、浪漫：靠姿态，不只靠形容词

| 模块 | 可追加的句子 | 检查重点 |
|---|---|---|
| 手托脸 | 一只手轻轻托着对方脸颊，手指在耳朵下面，自然弯曲。 | 逐根核手指，不把接触点画成粘连 |
| 越肩/背影 | 一人背对画面略偏一侧，只露耳朵和少许下颌；另一人面向画面。 | 仍能看清动作，不让后脑挡掉信息 |
| 风 | 几缕发丝和衣领被同一方向的风带起。 | 方向是气氛而非科学结论时才生图 |
| 暖边 | 外侧轮廓有一条细窄暖色平涂亮边，没有渐变。 | 不把整张脸涂黄 |
| 将吻未吻 | 鼻尖接近、双唇还没碰上，两人闭眼靠近。 | 不能把即将发生与已经发生混写 |

避免人物缩成远景小点，也别把全部情绪交给「温柔、浪漫」等抽象词。吉祥物若冲淡亲密氛围，可以不放；模板中 `COVER_EYES=None`。

### 现代情侣完整示例（适配稿）

```text
扁平矢量插画，丝网印刷风格，粗而均匀的深墨色轮廓线，大色块平涂，阴影只用半色调网点，没有渐变、没有写实质感。只用近黑深墨色、朱红、靛蓝、珊瑚粉、浅肤色和浅杏色；背景是纯品红抠像色，主体不使用品红，没有纹理或景物。近景，两位明显成年的现代情侣：一人背对画面略偏一侧，只露后脑、耳朵和一点下颌；另一人面向画面，闭眼，双唇轻轻相触，一眼能看出在接吻。一只手轻轻托着对方脸颊，手指在耳朵下面，自然弯曲。几缕头发和衣领被风吹向画面右侧。脸和头发外侧有一条细窄暖色平涂亮边，不涂到脸上，没有渐变。两人穿素色日常上衣，头发黑色；红晕是淡粉色、只在脸颊，嘴唇自然浅粉。人物半身，上方和左右留空，身体延伸出画面下缘。整张图无文字、数字、水印、品牌标志。
```

人物年龄、人数和动作按题修改；不得将未成年人形象用于此类亲密情境。框内暖底另外用代码实现。

## 三、古装与国别：环境组合辅助辨认

先核服饰，再用环境辅助读者辨认；月洞门、漏窗、瓦檐、园景等组合线索比单一饰物更明确。环境不是具体朝代已经考据正确的证明，领口方向与器物仍单独核。

### 构图参考（不是可直接抠成透明主体的整景）

```text
一面浅色粉墙，墙头一排瓦，墙上开一个圆形月洞门；门内是两位明显成年的古装人物，穿有依据的素色长衣，在门洞中近距离轻吻。门后能看见芭蕉叶与多孔假山石。人物和门洞均足够大，动作清楚，环境不被框裁掉；画面采用平涂、粗墨线与半色调，零文字。
```

普通 `art_grade.py` 的纯色抠像会把墙等环境一起去掉。优先把门、墙和园景写成代码场景，人物单独生图；若试整景，需另验调色、纹理和构图，不机械套主体抠图流水线。另一个候选是带窗格的漏窗；宫灯被裁掉后，国别线索可能随之消失。

白领、飘带、帽子或衣服配色可能让读者产生别国联想；这些只是假设线索，不是跨文化通用黑名单。先看实际生成结果，不凭一件道具给整个国家下定义。

## 四、其他情绪的画面模块

这些模块来自探索性例子，适配到新题后要重新看图；事实、结构与数量由代码或核查控制。

### 好笑：意外结果与身体反应

```text
一位明显成年的现代人物刚打开汽水，身体僵直地向后弹起，眼睛瞪圆，嘴张成圆形；上衣被少量泡沫溅到。瓶罐无品牌、无伪文字，人物半身，动作清楚。
```

泡沫、罐口和喷射方向需要精确时用代码叠加，人物负责反应；酒类题不必自动替换成汽水，按本题知识目的和基本安全原则选择。

### 温暖：包裹、湿眼含笑、暖色块

```text
一位明显成年的现代人物坐着，裹着柔软毯子，眼睛微湿、嘴角轻轻上扬；一大块暖色平涂光落在脸侧，神情被打动。半身构图，毯子、手与身体不粘连。
```

若鸡皮疙瘩是知识点，用代码小点或局部放大示意；不让表情和暖光替研究下结论。

### 敬畏：尺度差与仰视

```text
一只按核查特征绘制的昆虫背对观众，微微仰头；主体轮廓完整，四周留出纯色抠像背景，没有天空或地面。
```

夜空、星带和尺度差放在代码 `scene` 中实现。整幅银河生图容易漂向写实；深色虫体加 `outline`，先检查抠图碎点。生物到底是否会仰望、攀上某物，是待核查的动作断言，不能只为情绪加戏。

### 好奇：局部与观察动作

用人物或吉祥物的视线引向代码放大圈，再把微生物画在放大圈中。身体局部只露与题相关的范围；凹陷线条可能被误读为私处，需缩略图复看。把凹陷改成小点只是候选修法，不保证避免误读；细菌不默认加眼睛和人格。

### 尴尬/共鸣：想装作没事

```text
两位明显成年的现代人物并排，嘴角僵硬，试图装作没事，视线短暂移向对方后又移开；不要皱眉怒视，不画成冷战。
```

如果主题是步伐同步，腿的相位和同步数量由代码画，表情只作辅助；不能把「两人不高兴」当成已经画清同步。

## 五、未充分验证的情绪

紧张、悬疑、心疼、治愈、惊奇与反转等，先在方案中写目标及画面机制，再少量试图，不冒称模板已测通过。反转常靠两格对照，不一定需要生图。

情绪数字只作提醒：恶心≤5、害怕≤3、不适度≥6触发具体复看，不按分数一票否决。按 `references/12` 第十二节大胆制作、守基本原则，交内容负责人看成稿，觉得尺度不合再调整；平台规则与 AI 标识的证据边界见 `references/14-平台尺度与AI标识.md`。
